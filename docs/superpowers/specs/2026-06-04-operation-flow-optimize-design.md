# 操作流程优化 — 设计文档

## 目标

重构发票归档工具的核心操作流程，解决导入歧义、附件分散、筛选迟缓、标签硬编码、数据迁移覆盖等问题。

---

## 1. 数据模型重构

### 1.1 发票记录结构

```
Invoice
├── 固定解析字段（PDF 自动提取）
│   ├── invoice_no      # 发票号码
│   ├── invoice_date    # 开票日期
│   ├── invoice_type    # 发票类型（增值税专用/普通/票通…）
│   ├── buyer_name      # 购买方名称
│   ├── buyer_tax_id    # 纳税人识别号
│   ├── seller_name     # 销售方名称
│   ├── amount          # 金额
│   ├── tax_rate        # 征收率
│   ├── tax_amount      # 税额
│   ├── total           # 价税合计
│   ├── is_red          # 红票标记
│   └── file / pdf_path # 原始 PDF 路径
├── remark              # 备注（独立字段）
├── tags: dict[str,str] # 用户自定义标签 key:value
├── attachments: [str]  # 附件文件路径列表
└── error               # 解析错误信息
```

### 1.2 旧数据兼容

启动时自动检测旧数据格式：
- `screenshots` + `contracts` → 合并入 `attachments`
- `company` → 迁移为 `tags["企业号"]`
- `data/screenshots/` + `data/contracts/` → 迁移到 `data/attachments/`

### 1.3 存储目录

```
data/
├── invoices/        # 导入的发票 PDF 副本
├── attachments/     # 所有附件（原 screenshots + contracts）
└── invoices_data.json
```

标签模板配置存储在 `config.json`：

```json
{
  "data_dir": "...",
  "tag_templates": ["企业号"]
}
```

## 2. 导入流程

### 2.1 拖拽规则

| 拖入文件 | 行为 |
|---------|------|
| PDF | 始终按发票解析，不依赖选中状态 |
| 图片（png/jpg/…） | 若有选中行 → 添加为附件；无选中行 → 提示需选中 |
| 文档（docx/xlsx/…） | 同图片 |

### 2.2 解析结果处理

每张 PDF 解析完成后比对发票号：

| 结果 | 动作 |
|------|------|
| 发票号不重复 | 正常入库 |
| 发票号重复 | 弹窗"发票号 XXXXX 已存在（第 N 行），是否查看？" — "查看"跳转到对应行 / "忽略"关闭 |
| 无法解析（无发票号） | 若有选中行 → 提示"未识别到发票信息，是否添加为附件？"；无选中行 → 提示"无法识别为发票" |

### 2.3 拖拽视觉反馈

拖入文件经过窗口时显示半透明覆盖层：
- 提示文字（"导入 N 个发票 PDF" / "添加 N 个附件"）
- 文件类型图标

### 2.4 导入完成摘要

批量导入完成后弹出轻量结果弹窗：

```
导入完成
────────────────
✅ 成功导入   5 张
⚠ 解析失败   1 张（查看备注列）
🔄 重复跳过   2 张 [查看]
────────────────
[查看异常详情]     [关闭]
```

## 3. 附件管理

### 3.1 UI 合并

- 表格列"付款截图" + "合同" → 合并为"附件"列
- 列内显示：图标（图片/文档/PDF）+ 数量 + "查看"按钮 + "＋"按钮
- 查看 → 打开附件预览对话框（按类型分页或混合列表）

### 3.2 附件预览

按扩展名自动选择预览方式：

| 类型 | 预览方式 |
|------|---------|
| png/jpg/jpeg/bmp/gif/webp | 内置图片预览器 |
| pdf | 内置 PDF 预览器 |
| docx/doc/xlsx/xls | 系统默认程序打开 |

### 3.3 右键菜单精简

附件相关项从 8 项合并为 3 项：
- 添加附件
- 查看附件
- 清除全部附件

---

## 4. 标签系统

### 4.1 标签模板管理

设置对话框中新增标签管理区域：
- 显示当前已定义的标签列表
- 可新增标签名 / 删除已有标签 / 隐藏标签列
- "企业号"作为默认预置标签
- 修改后立即刷新表格列

### 4.2 表格交互

- 标签列继承模板中的标签名作为列头
- 单元格可双击编辑（与备注一致）
- 列头右键可隐藏该标签列
- 标签值参与全局搜索

---

## 5. 筛选与排序

### 5.1 实时过滤

- 下拉框（年份/月份/发票类型/销售方）：选项改变即时生效，去掉"筛选"按钮
- 文本输入框（购买方/企业号）：输入后 300ms 防抖自动过滤
- 去掉"筛选""重置"按钮，保留年份/月份的高级筛选面板

### 5.2 列头排序

- 点击列头 → 该列升序排列
- 再次点击 → 降序
- 第三次点击 → 取消排序
- 排序与筛选叠加生效

### 5.3 全局搜索

- Ctrl+F 弹出搜索框
- 搜索范围：固定字段 + 标签 + 备注
- 匹配行高亮，回车跳转下一个匹配

---

## 6. 数据迁移与备份

### 6.1 切换数据目录

```
新目录已有数据 → 弹窗选择：
  [保留新目录数据] [用旧数据覆盖] [取消]

新目录为空 → 弹窗选择：
  [迁移旧数据到新目录] [从空开始] [取消]
```

- 不自动覆盖，必须用户选择

### 6.2 旧数据自动迁移

- 启动时检测旧格式（`screenshots`/`contracts` 字段、`company` 字段）
- 自动迁移为新的 `attachments`/`tags` 格式
- 迁移完成后保存为新格式

---

## 7. 交互细节

### 7.1 表格点击行为

- 点击选中行不再取消选中（去掉 eventFilter 中的反选逻辑）
- 保持 SelectionBehavior: SelectRows

### 7.2 全局搜索

- Ctrl+F → 弹出搜索框（非模态，浮在表格上方）
- 输入即搜索，匹配行高亮
- Enter → 跳转到下一个匹配行
- Esc → 关闭搜索

### 7.3 状态栏

- 始终显示当前记录总数和筛选状态
- 简化提示文字

## 涉及文件

| 文件 | 改动范围 |
