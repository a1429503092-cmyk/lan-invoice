# 设置窗口综合优化

## 当前问题

- 仅显示数据目录路径，缺少统计信息
- 窗口固定 560x320，内容拥挤
- 无数据备份/恢复功能
- 无版本号和系统信息展示
- 视觉比较简单

## 优化方案

### 1. 信息增强

在数据存储卡片中增加实时统计：
- 发票记录条数
- 截图文件数量
- 合同文件数量
- 数据总大小（KB/MB）

在标题区显示版本号（从代码版本获取）。

### 2. 布局视觉优化

- 窗口尺寸：560x320 → 580x420
- 三张卡片用统一风格，不同颜色区分：
  - 数据存储（蓝色）
  - 软件另存（绿色）
  - 备份恢复（橙色）
- 每张卡片内信息紧凑，卡片间间距 10px
- 路径文本使用等宽字体，超出时省略号

### 3. 功能增强：数据备份与恢复

新增第三张卡片"数据备份与恢复"：
- **备份当前数据**：将所有数据文件（JSON + 截图 + 合同 + 发票 PDF）打包为 ZIP，文件名含日期时间，弹出保存对话框
- **恢复数据**：选择之前备份的 ZIP 文件，解压到当前数据目录，替换现有数据（需二次确认），恢复后自动重载

### 4. 视觉统一

按钮样式统一，三种主题色：
- 数据：蓝色 (#1E6FBF)
- 另存：绿色 (#2E7D32)
- 备份：橙色 (#E06020)

## 涉及文件

- `src/dialogs.py` — `SettingsDialog` 类，约 200 行需要重写

## 依赖

- Python stdlib `zipfile` 用于打包/解压
- 现有 `shutil` `os` 已导入
