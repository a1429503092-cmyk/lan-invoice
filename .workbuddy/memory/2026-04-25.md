# 2026-04-25 工作日志

## 发票识别工具

- 用户需求：识别电子增值税专用发票PDF，提取购买方名称、纳税人识别号、金额、征收率、税额；支持手动输入企业号、累计统计、导出Excel。
- 示例文件：`C:/Users/dell/Desktop/发票/14786-福建长富乳品有限公司.pdf`
- 工具文件：`c:/Users/dell/WorkBuddy/20260425180357/invoice_tool.py`
- 技术栈：Python 3.13 + PyQt5 + pdfplumber + openpyxl
- 解析方式：用 pdfplumber 提取文本后用正则匹配各字段
- 关键正则坑：购买方名称和销售方名称在同一行，需用"销"字截断

## v2.0 新增功能（2026-04-27）
- 付款截图：每张发票可添加多张截图，截图复制到 screenshots/ 目录，路径存入 JSON 持久化
- 截图查看：弹出大图预览对话框，支持多张翻页
- 按月筛选：工具栏年份+月份下拉框，筛选后汇总栏同步显示筛选结果，导出Excel只导出筛选数据
- Excel不导出截图列

## v4.0 新增功能（2026-04-27）
- 软件改名：「发票识别工具」→「发票归档」，标题/应用名均已更新
- 新增合同列：每张发票可绑定多份合同（PDF/Word/Excel），存入 contracts/ 目录
- 合同管理对话框：列表展示、双击打开（系统默认程序）、另存下载、从列表移除
- 合同添加三种方式：文件夹选择（＋按钮）、拖拽文件到窗口（需先选中行）、Ctrl+V 粘贴文件路径
- Ctrl+V 智能判断：图片数据→截图，图片文件→截图，合同文件→合同
- 拖拽智能判断：有选中行时PDF视为合同，无选中行时PDF视为导入发票
- Excel 不导出截图和合同列
- 状态：完成，语法检查通过，打包为 invoice_archive_v4.zip
